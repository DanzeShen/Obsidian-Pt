# 葡萄牙语规则动词变位对照

> 三动词：**falar**（-ar）· **comer**（-er）· **partir**（-ir）
> 每行人称顺序：陈述式/虚拟式/人称不定式为 **eu → você(ele/ela) → nós → vocês(eles/elas)**；命令式为 **você → nós → vocês**。

| Infinitivo 不定式  |                                              | falar   | comer   | partir   |
