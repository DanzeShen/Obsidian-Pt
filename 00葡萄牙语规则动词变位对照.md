# 葡萄牙语规则动词变位对照

> 三动词：**falar**（-ar）· **comer**（-er）· **partir**（-ir）
> 每行人称顺序：陈述式/虚拟式/人称不定式为 **eu → você(ele/ela) → nós → vocês(eles/elas)**；命令式为 **você → nós → vocês**。

## 非人称形式 Formas Nominais

| 时态              | falar   | comer   | partir   |
| --------------- | ------- | ------- | -------- |
| Infinitivo 不定式  | falar   | comer   | partir   |
| Gerúndio 副动词    | falando | comendo | partindo |
| Particípio 过去分词 | falado  | comido  | partido  |

## 命令式 Imperativo

> 人称顺序：você → nós → vocês

| 时态                    | falar       | comer       | partir       |
| --------------------- | ----------- | ----------- | ------------ |
| Imperativo Afirmativo | fale        | coma        | parta        |
| 肯定命令式                 | falemos     | comamos     | partamos     |
|                       | falem       | comam       | partam       |
| Imperativo Negativo   | não fale    | não coma    | não parta    |
| 否定命令式                 | não falemos | não comamos | não partamos |
|                       | não falem   | não comam   | não partam   |
