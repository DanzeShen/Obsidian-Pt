# 葡萄牙语规则动词变位对照

> 三动词：**falar**（-ar）· **comer**（-er）· **partir**（-ir）
> 每行人称顺序：陈述式/虚拟式/人称不定式为 **eu → você(ele/ela) → nós → vocês(eles/elas)**；命令式为 **você → nós → vocês**（已删除 tu 第二人称）。

## 非人称形式 Formas Nominais

| 式     | 时态              | falar   | comer   | partir   |
| ----- | --------------- | ------- | ------- | -------- |
| 非人称形式 | Infinitivo 不定式  | falar   | comer   | partir   |
| 非人称形式 | Gerúndio 副动词    | falando | comendo | partindo |
| 非人称形式 | Particípio 过去分词 | falado  | comido  | partido  |
