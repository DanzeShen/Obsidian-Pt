# Dar uma olhada：-ada / -ida 名词和它「随便做一下」的意味

巴西人用 -ada 或 -ida 把动词变成名词，再用 dar 递出去：dar uma olhada（看一下）、dar uma estudada（学一下）。这个后缀让动作变短、变随意、不构成承诺—— **中文的动词重叠（看看、试试）和「一下」干的正是这件事** 。同一个词尾还能表示某样东西打出来的一击（facada）、一群人（criançada）和一份的量（colherada），后两者正好对上中文的量词。

### 结构

dar uma + 动词词干 + -ada/-ida = 随便做一次 · dar uma olhada EM algo（看一下某物）—— -ada 还表示一击（facada）· 一群人（criançada）· 一份的量（colherada）

### 快速概览

- 名词从分词造出来： **\-ar** 动词取 **\-ada** ， **\-er** 和 **\-ir** 动词取 **\-ida** ： *olhar → uma **olhada*** 、 *sair → uma **saída*** 、 *correr → uma **corrida*** 。
- 日常框架是 **dar uma + -ada** ： *Vou **dar uma olhada*** （我看一下）。 *Dei **uma limpada** na cozinha.*（我把厨房扫了一下。）
- 它让动作变得 **短暂、随意、不构成承诺** —— *vou estudar* 承诺的比 *vou **dar uma estudada*** 多得多。 **这个差别就是本课的全部。**
- **中文的对应是动词重叠和「一下」** ： *dar uma olhada* = **看看／看一下** ， *dar uma dormida* = **睡一会儿** 。
- 补语用 **em** ，不是 *de* ： *Dá uma olhada **no** contrato.*
- **\-ada** 还给某样东西打出来的一击命名： *faca → **facada*** 、 *cotovelo → **cotovelada*** 。你 *dar* 一下，或者 *levar* 、 *tomar* 一下。
- 它也把人收成一群 —— *criança → **criançada*** 、 *rapaz → **rapaziada*** —— 而且这一群配 **单数** 动词。
- 它还量出一份： *colher → **colherada*** （一勺）、 *dente → **dentada*** （一口）。中文的 **量词** 正好对上。

### 为什么重要？

这是把「正确的葡语」和「巴西的葡语」分开的型之一。 *Dá uma olhada aí* （你看一下这个）是同事把文件递给你的方式， *vou dar uma melhorada nisso* （我改一下）是工作被半承诺出去的方式。

没抓住这个型，你听到的是 *dar* （给）加上一个字典里只收在动词条下的词。会用它，你就不再听起来像在翻译： *vou limpar a casa* （我要打扫房子）和 *vou dar uma limpada na casa* （我把房子扫一下）之间的距离，就是 **承诺** 和 **帮个忙** 之间的距离。

中文母语者在这里顺风很大。汉语的 **看看／看一下／试试／歇一会儿** 就是专门表达「轻轻地做一次」的装置，而且 **社交功能也一样** ：中文里「帮我看一下」比「帮我校对一遍」更容易得到「好」，葡语的 *dar uma olhada* 比 *revisar* 更容易得到 *sim* ，理由完全相同。

### 深入解析

### 1\. 这个名词是换了顶帽子的分词

怎么造你已经会了。取动词，做出过去分词，变成阴性，当名词用： **\-ar** 动词给 **\-ada** ， **\-er** 和 **\-ir** 动词给 **\-ida** 。它永远是阴性，而且几乎总带着 *uma* 。

| 动词 | 名词 | 意思 |
| --- | --- | --- |
| *olhar* （看） | *uma **olhada*** | 看一下 |
| *limpar* （打扫） | *uma **limpada*** | 扫一下 |
| *estudar* （学习） | *uma **estudada*** | 学一下 |
| *melhorar* （改善） | *uma **melhorada*** | 稍微好一点 |
| *sentar* （坐） | *uma **sentada*** | 坐一会儿 |
| *passar* （路过） | *uma **passada*** | 顺道一趟 |
| *correr* （跑） | *uma **corrida*** | 跑一趟、一单网约车 |
| *sair* （出去） | *uma **saída*** | 出口、出去玩一晚 |
| *subir* （上升） | *uma **subida*** | 一段上坡 |
| *dormir* （睡） | *uma **dormida*** | 睡一觉 |

把右边那一列竖着读，中文一侧全是 **「一下」「一会儿」「一趟」** 。葡语用词尾干的事，中文用这些说法干。

指小形还能叠在上面，巴西人不停地用它把动作变得更小： *uma olhadinha* （瞄一眼）、 *uma saidinha* （出去一小会儿）。相当于中文再加一层「就一眼」。

### 2\. dar uma 对意思做了什么

这才是本课的核心。下面每一对的两半都是正确的葡语，承诺的工作量却完全不同：

- *Vou **limpar** a casa.*（我要打扫房子。）—— 认真地，一间一间来。
- *Vou **dar uma limpada** na casa.*（我把房子扫一下。）—— 二十分钟，差不多就行。
- *Preciso **estudar** para a prova.*（我得为考试复习。）—— 好几个晚上，有计划。
- *Preciso **dar uma estudada** para a prova.*（我得为考试看一下。）—— 把笔记翻一遍。

这个说法让动作变得 **短暂、随意、不构成承诺** ，而巴西人正是在想要这个效果时伸手拿它。

它也是你在开口求人之前先把请求缩小的办法： *Você pode **dar uma olhada** no meu texto?*（你能帮我看一下这段文字吗？）比 *Você pode **revisar** meu texto?*（你能帮我校对吗？）少要走对方一晚上，所以前者更容易得到「好」。

**这套社交计算中文母语者本来就在做。** 「帮我看一下」和「帮我校对一遍」的差别，正是同一件事。

主语不是人时它也照样工作，通常带着「稍微好转」的意思：

- *O tempo **deu uma melhorada** hoje à tarde.*（今天下午天气好了一点。）
- *A dor **deu uma acalmada** depois do remédio.*（吃了药以后疼痛缓和了一点。）

### 3\. -ada 表示某样东西打出来的一击

同一个词尾接在名词上——工具、武器、身体部位——就给出 **用它打的一下** ：

| 东西 | 一击 | 意思 |
| --- | --- | --- |
| *faca* （刀） | **facada** | 捅一刀 |
| *cotovelo* （手肘） | **cotovelada** | 撞一肘 |
| *cabeça* （头） | **cabeçada** | 顶一头 |
| *joelho* （膝盖） | **joelhada** | 顶一膝 |
| *martelo* （锤子） | **martelada** | 锤一下 |
| *pedra* （石头） | **pedrada** | 砸一石头 |

**中文用量词做同一件事** ：捅了 **一刀** 、撞了 **一肘** 、砸了 **一石头** 。工具的名字变成那一击的名字，思路完全相同。至于你在哪一头，由动词告诉你： **dar** 是打出去， **levar** 或 **tomar** 是挨了一下。

- *O zagueiro **deu** uma cotovelada no atacante.*（后卫给了前锋一肘。）
- *O atacante **levou** uma cotovelada no rosto.*（前锋脸上挨了一肘。）

有两件事值得知道。 *Pé* （脚）是那个你以为会合群却不合群的例外：一脚是 *um chute* 或 *um pontapé* ，绝不是 *\-ada* 的词。另外 *facada* 还有一段完全和平的人生，意思是「宰客」—— *Que facada!*（太宰人了！）是账单来了时巴西人会说的话。

### 4\. -ada 表示一群

接在表示人的词上， *\-ada* 把他们收成一个温暖、随意的集合名词： *criança → **criançada*** （孩子们）、 *moleque → **molecada*** （小屁孩们）、 *rapaz → **rapaziada*** （哥们儿们）、 *mulher → **mulherada*** （女士们）、 *garoto → **garotada*** 。南部还有自己的：南里奥格兰德的 *gurizada* ，巴拉那的 *piazada* 。

绊住学习者的语法细节是：它们在 **语法上是单数** ，和 *a galera* （那帮人）一样。

- *A criançada **está** no quintal.*（孩子们在院子里。）
- *A rapaziada **chegou** cedo.*（哥们儿们来得早。）

**中文母语者对此毫无障碍** ：中文的动词不变形，而且「一帮人」「大家」本来就当整体看。语法书要求这个单数，尽管在放松的口语里偶尔会滑出一个复数动词。另外 *rapaziada* 还能用来称呼一群人： *E aí, rapaziada!*（嘿，各位！）

### 5\. -ada 表示一份的量

同一个后缀的第三份活：一份，由装它的东西来量。 *colher → **colherada*** （一勺）、 *garfo → **garfada*** （一叉）、 *dente → **dentada*** （一口）、 *braço → **braçada*** （一抱，也指游泳的一划）。

**这里又是中文的量词** ：一 **勺** 糖、一 **口** 面包、一 **抱** 柴。你的母语在这方面比葡语还发达，直接套用即可。

这里有一个陷阱：「相当多」用的是阳性的 *um bocado* ，不是 *\-ada* 的词 —— *um bocado de gente* （不少人）。

### 6\. 邻居们：-eco、-alhão、-eira、-ice

这些是态度后缀。它们不给东西分类，而是告诉听者你怎么看它。

- **\-eco** 带着轻蔑把东西变小： *livro → **livreco*** （一本破书）、 *jornal → **jornaleco*** （小报）。
- **\-alhão** 带着讥讽把东西变大： *grande → **grandalhão*** （大块头）。
- **\-eira** 和 **\-ice** 给行为本身命名： *besteira* （废话）、 *bobeira* （傻事、瞎耗时间）、 *chatice* （讨厌事）、 *burrice* （愚蠢）。

### 7\. 这些东西住在哪里

各个社会阶层的巴西口语，加上消息、工作群聊和任何非正式的书写。它待在学术散文和正式报告之外——在那里，一个 *olhada* 会变成 *uma breve análise* （一次简要分析）。

不过最后请注意一件事：这个型有一半已经冻进了普通词汇，没人再把它们听成非正式。 *Entrada* （入口，也指前菜）、 *saída* （出口）、 *chegada* （到达）、 *comida* （食物）、 *bebida* （饮料）、 *batida* （车祸，也指一种鸡尾酒）、 *corrida* （赛跑、跑步、一趟车）全都是这个后缀，就明晃晃地坐在你从 A1 起就拥有的词汇里。

### 常见错误

- **补语用 *de* 。** 这个说法要 **em** ：❌ *dar uma olhada do relatório* → ✅ *dar uma olhada **no** relatório* （看一下报告）。其他也一样： *dar uma passada **na** casa da minha mãe* 、 *dar uma melhorada **no** texto* 。别被中文的「看一下 **报告** 」带走。
- **给集合名词配复数动词。** ❌ *A criançada estão* → ✅ *A criançada **está** no quintal.*（孩子们在院子里。）它在语法上是单数。
- **把一击的方向弄反。** *dar* 是打出去， *levar* / *tomar* 是挨了。❌ *Levei uma cotovelada no atacante* 说不通。
- **把每个「一下」都翻成这个形式。** *dar uma + -ada* 是专门让动作变轻的装置，不覆盖所有的「一下」。时间上的「等一下」是 *espera um pouco* ，量上的「一点点」是 *um pouquinho* 。
- **在正式文章里用它。** 学术论文和正式报告里不放它，那里会换成 *uma breve análise* （一次简要分析）。就像中文报告里不会写「我看了一下」。
- **给「踢」造一个 *\-ada* 。** ❌ *peada* 这样的词不存在。一脚是 *um chute* 或 *um pontapé* 。
- **把冻住的词拆得太狠。** *comida* （食物）、 *bebida* （饮料）、 *entrada* （入口）已经是普通名词，不是「吃一下」。上一节那句「前缀给的是街区不是门牌号」在这里同样有效。
