# 宾语、补足语和表语

巴西葡语里的句子常常围绕直接宾语、间接补足成分和表语展开。只要看清这些成分的作用，较长的分句就会更容易理解，也更容易自己产出。

### 结构

动词 + 直接宾语 / 动词 + 介词补足语 / 主语或宾语 + 表语

### 快速概览

- 直接宾语 = 基本形式里通常没有介词
- 很多补足语需要介词
- 表语描述主语或宾语的状态、身份或结果

### 为什么重要？

当你能区分宾语、补足语和表语时，句子的内部结构会清楚很多。这会直接影响代词使用、一致关系、被动式理解，以及更复杂从句的构建。

### 核心概念

巴西葡语里的句子常常围绕直接宾语、带介词的补足语以及表语成分来扩展。只要把这些功能看清楚，较长的句子就会更容易理解，也更容易自己造出来。

一旦你能分清宾语、补足语和表语，句子的内部逻辑就会清晰得多。这会直接影响代词使用、一致关系、被动结构和从句搭建。

### 结构一览

- 动词 + 直接宾语 / 动词 + 介词补足语 / 主语或宾语 + 表语

### 如何运作

1. 直接宾语通常回答“什么？”或“谁？”：“comprei o ingresso”。
2. 介词补足语依赖于动词、名词或形容词：“gostar de música”、“precisar de ajuda”。
3. 主语表语说明主语是什么样，或变成了什么：“o apartamento está vazio”。
4. 宾语表语说明某人把宾语称作、看作或变成什么：“chamaram o menino de gênio”。

### 用法与语体

- 有些动词可以搭配不同的补足模式，含义也会有细微变化。
- 这课关注的是句法功能，而不只是词汇选择。

### 常见陷阱

- 有介词并不自动等于“间接宾语”；它也可能是别的补足语。
- 有些动词允许不止一种结构，而且语义会略有不同。
