# 语气与体作为系统

语气体现说话人对动作的立场，而体体现动作是如何展开的。把两者放在一起看，时态选择就会更连贯。

### 结构

直陈式 / 虚拟式 / 命令式 + 完整体 / 未完成体 / 进行体的取值

### 你的进度

尚未开始

### 快速概览

- 语气 = 说话人的立场
- 体 = 对动作内部展开方式的观察
- 时态、语气和体是一起运作的

### 为什么重要？

这是理解整个动词系统的概念地图。一旦语气和体变得可见，单个时态就不再像彼此孤立的列表。

### 深入解析

### 主要规则

- 直陈式通常用于陈述事实、事件和断言。
- 虚拟式通常出现在不确定、愿望、评价、条件或尚未断定的内容中。
- 命令式表达命令、邀请和指示。
- 体关注动作是被看成完整、进行中、习惯性的、开始中的、重复的，还是刚完成的。
- 葡语的时态选择通常同时反映语气和体，而不只是一个日历时间标签。

### 使用说明

- 同一个时间点可以用不同的体貌解读来表达。
- 语气和体解释了为什么一些看起来相似的动词形式在实际话语中行为不同。

### 例子

| Portuguese | Meaning |
| --- | --- |
| Ele chegou ontem. | 他昨天到了。 |
| Ele chegava cedo. | 他以前常常早到 / 他当时正早早到达。 |
| Talvez ele chegue hoje. | 也许他今天会到。 |
| Chega cedo amanhã. | 明天早点到。 |
| Acabei de sair. | 我刚离开。 |
| Ele chegava cedo. | 他以前常常早到。 |
| Já acabei de sair. | 我刚刚已经离开了。 |

- 真实用法有时会拉伸学校语法里的分类，尤其在非正式口语中。
- 词汇本身的意义和语境也会影响体貌解释。
