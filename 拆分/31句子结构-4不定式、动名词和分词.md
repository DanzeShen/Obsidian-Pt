# 不定式、动名词和分词

葡语有三种主要的非限定动词形式：不定式、动名词和分词。它们帮助构成动词短语、名词化结构和缩减从句。

### 结构

不定式 / 动名词 / 分词

### 你的进度

尚未开始

### 快速概览

- 不定式用来给动作命名
- 动名词突出过程感
- 分词通常表示结果，或参与复合结构

### 为什么重要？

这些形式把整个动词系统连接在一起。一旦它们清楚了，体貌、被动语态和缩减从句都会更容易理解。

### 深入解析

### 主要规则

- 不定式用于给动作命名，或和助动词、介词连用：\`"estudar"\`、\`"para estudar"\`。
- 动名词常用来表达进行中的过程或伴随动作：\`"estou trabalhando"\`、\`"falando sério"\`。
- 分词常出现在复合时态、被动形式和结果状态中：\`"feito"\`、\`"aberto"\`、\`"resolvido"\`。
- 这些形式不像限定动词那样显示完整的人称一致。

### 使用说明

- 人称不定式是后续内容，会在单独的一课里讲。
- 用这些形式构成的缩减从句从 B2 开始会变得特别重要。

### 例子

| Portuguese | Meaning |
| --- | --- |
| Viajar é bom. | 旅行很好。 |
| Estou trabalhando agora. | 我现在正在工作。 |

| Para estudar melhor, preciso de silêncio. | 为了更好地学习，我需要安静。 |
| Falando sério, isso importa. | 认真地说，这很重要。 |

### 常见陷阱

- 有些分词是不规则的，需要按词汇单独记忆。
- 动名词在巴西葡语里非常强势，尤其常出现在表示正在进行的动词短语中。
