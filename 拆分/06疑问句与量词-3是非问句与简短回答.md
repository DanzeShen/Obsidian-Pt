# 是非问句与简短回答

在巴西葡萄牙语中，只需用升调就能提问，无需任何助词，也无需改变语序。妙处在于回答：巴西人通常不说 sim，而是把问句里的动词"回传"回去——就像中文里"你去吗？→ 去/不去"一样自然。

### 结构

陈述句 + 升调（↗）= 疑问句 · 回答时将动词调为自己的人称再送回去

### 快速概览

- 只需提高语调即可提问——无需助词，无需调换语序
- 巴西式回答： **把问句里的动词"回传"给对方** ，但要变成自己的人称
- *Você fala inglês?* → *Falo.*（你问的是 você，我回答的是 eu：fala → falo）
- 否定回答： **não** + 动词 —— *Não falo* （单说一个 *não* 会显得生硬）
- 单用 *sim* 没有错，只是听起来略显正式；回传动词更自然、更有温度
- 是非之间还有许多色彩： *Claro!*、 *Acho que sim* 、 *Ainda não* 、 *De jeito nenhum!*
- 情态动词同样要换人称： *Posso entrar?* → *Pode.*
- 附加疑问词 *né?*、 *não é?*、 *tá?* 同样用回传动词作答

### 为什么重要？

是非问句是你每天的生命线—— *Tem WiFi?*、 *Aceita cartão?*、 *Pode me ajudar?* 发问很容易：语调往上一挑就行。真正让你听起来像巴西人的，是回答——要伸手去拿那个动词，而不是机械地说 sim。只要掌握了这一点，一句简单的 *Você gosta daqui? — Gosto!* 就会浑然天成，本地人也能感受到你真心融入了对话。

### 深入解析

你已经掌握了容易的那半部分：把一句陈述句的语调往上提，就变成是非问句。 *Você fala inglês.* → *Você fala inglês?* ↗ 无需任何助词，无需调换语序，无需变动词形式，就这么简单。

这节课真正的精华在于 **回答** ——因为巴西人通常不会单说 sim。

### 巴西式"肯定"：回传动词

把问句里的动词取出来，变成 **自己的人称** 送回去，而不是说 *sim* ：

| 问句（关于 você） | 自然回答（关于 eu） |
| --- | --- |
| Você **fala** inglês? | **Falo.**（我会。） |
| Você **mora** aqui? | **Moro.**（我住。） |
| Você **tem** tempo? | **Tenho.**（我有。） |
| Você **gosta** de café? | **Gosto.**（我喜欢。） |

注意那个小小的"人称跳跃"：问句问的是 *você* ，但你回答的是 *eu* ，所以 **fala → falo** ， **tem → tenho** 。只需把动词对应到真正在做这件事的人：

- *Vocês moram aqui?* → ***Moramos.***（我们住。）
- *Ela trabalha hoje?* → ***Trabalha.***（她上班。）

这与中文的思维方式如出一辙——"你去吗？→ 去 / 不去"，巴西人也是把动词本身送回去。真正新鲜的地方只有一点：动词要跟着人称变形（fala → falo），而中文不需要这一步。

单说 *sim* 没有语法错误，只是听起来略显正式或简短；回传动词听起来更热情，像是真正投入了对话。

### 巴西式"否定"：não + 动词

否定时，先说 **não** ，再回传动词（单说一个 *não* 会显得生硬）：

- *Você fuma?* → ***Não fumo.***
- *Tem leite?* → ***Não tem.***
- *Você é casado?* → ***Não sou.***

### 是与非之间的整个光谱

真实的回答很少是干巴巴的是或否：

| 偏肯定 | 偏否定 |
| --- | --- |
| Claro!（当然！） | Ainda não.（还没呢。） |
| Com certeza!（肯定！） | Acho que não.（我觉得不是。） |
| Acho que sim.（我觉得是。） | De jeito nenhum!（绝对不行！） |
| Sim, claro. | Não, obrigado / obrigada. |

### 容易踩坑的动词

- **tem** （有 / 存在）： *Tem troco?* → *Tem.* / *Não tem.*
- **é** （ser 动词，是）： *É longe?* → *É.* / *Não é.*
- **pode / posso** （情态动词——注意人称！）： *Posso entrar?* → *Pode.*（你可以） · *Você pode esperar?* → *Posso.*（我可以）
- **tá** （estar 的口语形式）： *Tá pronto?* → *Tá.* / *Não tá.*

### 你已经认识的附加疑问词

在句尾加上附加疑问词，就是在邀请对方说"是"： *Você vai, **né**?* · *É aqui, **não é**?* · *Vamos, **tá**?* 回答依然是回传动词： *Você vai, né?* → *Vou!*

### 例子

### 日常服务场景

- " **Aceita** cartão?" " **Aceito.**"（收刷卡吗？——收。）
- " **Tem** troco?" " **Não tenho.**"（有零钱吗？——没有。）
- " **Está** aberto?" " **Está.**"（开着吗？——开着。）
- " **Pode** parcelar?" " **Pode.**"（可以分期吗？——可以。）

### 约好出行

- "Você **vai** na festa?" " **Vou.**"（你去派对吗？——去！）
- " **Quer** carona?" " **Quero!**"（要搭车吗？——要！）
- " **Vamos** juntos?" " **Vamos.**"（一起去？——走吧！）
- " **Pode** ser amanhã?" " **Pode.**"（明天行吗？——行。）

### 个人问题

- "Você **mora** sozinho?" " **Não moro.**"（你一个人住吗？——不是。）
- " **Gosta** de praia?" " **Adoro!**"（喜欢海滩吗？——超喜欢！）
- " **Fala** espanhol?" " **Um pouco.**"（会说西班牙语吗？——一点点。）
- " **Conhece** São Paulo?" " **Conheço.**"（你去过圣保罗吗？——去过。）

### 附加疑问句

- "Tá cansado, **né**?" " **Tô.**"（累了吧？——是的。）
- "É brasileiro, **não é**?" " **Sou.**"（你是巴西人吧？——是的。）
- "Fica aqui, **tá**?" " **Tá bom.**"（待在这里，好吗？——好的。）

### 混合式回答

- "Tem café?" " **Tem, mas é pouco.**"（有咖啡吗？——有，但不多了。）
- "Pode esperar?" " **Posso, mas não muito.**"（你能等吗？——能，但不能太久。）
- "Gosta de pizza?" " **Depende do sabor.**"（喜欢披萨吗？——看口味。）

### 常见例外

### obrigado 可能是"不用了，谢谢"

有人向你提供东西而你不想要？一句 *obrigado / obrigada* ——通常配上轻轻摆手——意思是"不用了，谢谢"，而不是"好的"：

- "Aceita um cafezinho?" → " **Obrigada.**"（= 不用了，谢谢。）
- 要接受的话，说清楚：" **Aceito, obrigada!**" 或 " **Pode ser!**"

### 情态动词会"翻转"人称

动词回传的是 **真正在做这件事的人** ，所以情态动词的回答往往换了人称：

- "Posso entrar?" → " **Pode.**"（你问的是自己能不能进来 → 我告诉你"你可以"）
- "Você pode me ajudar?" → " **Posso.**"（你问的是我能不能帮你 → "我可以"）

### 如何温柔地说"不"

干巴巴的 *Não.* 听起来可能相当生硬。软化一下：" **Não, obrigado** "、" **Hoje não** "、" **Agora não dá** "（现在不行）、" **Acho que não.**"

### né? 其实不是真正的疑问

附加词 *né?* 只是在邀请对方表示同意——你是在确认，而不是真的在发问。巴西人几乎什么句子后面都会加上它："Tá calor hoje, **né**?"

### 趣闻

巴西葡萄牙语里有一个最可爱的小陷阱： *Pois não?* 意思是"有什么需要帮忙的吗？"——是肯定的语气，尽管里面明晃晃地坐着一个 *não* 。它是从古老的短语 *pois não havia de* （大意是"我怎么可能不……"）磨损演变而来的。所以当店员用 *pois não* 来招呼你时，放心——那是热情的"当然，请说。"
