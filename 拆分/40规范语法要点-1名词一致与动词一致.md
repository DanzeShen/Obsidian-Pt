# 名词一致与动词一致

一致把句子里的词联在一起。在更受监控的写作里，名词一致和动词一致会成为核心规范。

### 结构

名词短语内部一致 / 主语-动词一致

### 你的进度

### 快速概览

- 名词一致发生在名词短语内部
- 动词一致把动词和主语连起来
- 集体表达和固定搭配要特别注意

### 为什么重要？

一致是细心读者最先注意到的地方之一。句子结构即使正确，如果一致薄弱，整篇文字都会显得不够受控。

### 深入解析

### 核心概念

一致把句子里的词联在一起。在更受监控、更讲究的书面语里，名词一致和动词一致是中心规范之一。

细心的读者最先注意到的，常常就是一致。句子结构也许没问题，但一致一弱，整篇文字都会显得不够稳。

### 结构概览

- 名词短语内部的一致
- 主语和动词之间的一致

### 如何运作

1. 在名词短语内部，冠词、数词、形容词以及某些数量词要和名词一致。
2. 限定动词要和语法主语一致。
3. 集体和部分结构可以根据构造和焦点吸引单数或复数：a maioria das pessoas chegou/chegaram。
4. 某些固定表达在正式写作中特别重要：é proibido/proibida, obrigado/obrigada。

### 用法与语体

- 口语里有时会放松一致，但正式写作通常会保留。
- 一致取决于句法结构，而不只是取决于语义。

### 常见陷阱

- 有些部分结构允许不止一种一致模式。
- 非正式口语可能容忍一些在正式写作里显得不稳的结构。

### 例子

| 葡语 | 含义 |
| --- | --- |
| As casas antigas foram vendidas. | 那些老房子被卖掉了。 |
| A maioria das pessoas chegou cedo. | 大多数人早到了。 |
| A maioria das pessoas chegaram cedo. | 大多数人早到了。 |
| Entrada proibida. | 禁止入内。 |
| Muito obrigada. | 非常感谢。 |
| Os documentos estavam organizados. | 文件整理得很整齐。 |
