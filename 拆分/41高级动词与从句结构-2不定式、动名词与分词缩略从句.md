### 核心概念

缩略从句不用完整的限定式从句，也能表达时间、原因、条件、让步、目的或结果等关系。

掌握缩略从句，会让你更容易读懂信息密度更高的文本，也能让你的写作更紧凑、更有节奏感。

### 结构速览

### 主要规则一览

| 步骤 | 规则 |
| --- | --- |
| Rule 1 | 不定式从句可以替代完整的从属从句，尤其常见于介词之后，例如 ao chegar、para resolver。 |
| Rule 2 | 动名词从句经常表示方式、时间、原因或背景动作，例如 estudando assim, você melhora。 |
| Rule 3 | 过去分词从句常用来表示先前已经形成的结果或状态，例如 terminada a reunião, fomos embora。 |
| Rule 4 | 缩略从句能压缩信息，在正式写作以及部分口语风格里都很常见。 |

### 它是怎么运作的

1. 不定式从句可以替换完整的从属从句，尤其是在介词后面，例如 ao chegar、para resolver。
2. 动名词从句往往表示方式、时间、原因或背景动作，例如 estudando assim, você melhora。
3. 过去分词从句通常用来交代先前的结果或状态，例如 terminada a reunião, fomos embora。
4. 缩略从句会把信息压缩得更紧凑，因此在正式书面语和部分口语里都很常见。

### 使用与语体

- 即使连接成分更轻，缩略从句与主句之间仍然保留明确的语义关系。
- 当主语需要明确说出时，缩略从句内部常会出现人称不定式。

### 常见陷阱

- 不是每一个从属从句都能在所有语境里自然地缩略。
- 动名词式缩略很常见，但风格是否自然、表达是否清楚仍然重要。

### 例子

| 葡语 | 中文意思 |
| --- | --- |
| Ao chegar, me avisa. | 你一到就告诉我。 |
| Para resolver isso, precisamos de tempo. | 要解决这个问题，我们需要时间。 |
| Estudando todo dia, você melhora. | 每天学习，你就会进步。 |
| Terminada a reunião, fomos embora. | 会议一结束，我们就离开了。 |
| Mesmo sem saber tudo, ele respondeu. | 即使不知道全部情况，他还是回答了。 |
