# 介词后的代词：para mim、comigo，以及 para eu fazer

介词后面 *eu* 变成 **mim** ， *tu* 变成 **ti** ——其余代词保持原样——而 *com* 会融合成 *comigo* 、 *contigo* 、 *conosco* 。真正决定你听起来有没有受过教育的，是 *para mim* 和 *para eu* 的分工：代词只是坐在介词后面时用 **mim** ，代词是 **后面那个动词的执行者** 时用 **eu** 。中文其实做同样的区分：「给我」没有动词，「给我 **读** 」有动词。

### 结构

介词 + mim / ti / você / ele / ela / nós / a gente / vocês / eles / elas · com + eu/tu/nós = comigo / contigo / conosco · para + eu/você/ele + 不定式（代词是下一个动词的执行者时）：para eu fazer = 为了我来做

### 快速概览

- 介词后面只有两个代词会变形： *eu* → **mim** 、 *tu* → **ti** 。其余保持原样： *para você* 、 *com ele* 、 *sem vocês* 、 *de nós* 。
- **com** 会融合成一个词： **comigo** 、 **contigo** 、 **conosco** ——但 *com você* 、 *com ele* 、 *com a gente* 仍是两个词。
- 关键规则：代词只是宾语时用 **mim** （ *Isso é para **mim*** ），代词是后面不定式的主语时用 **eu** （ *Isso é para **eu** fazer* ）。
- **一秒判断法** ：代词后面 **紧跟动词吗** ？有动词 → *eu* 。没有 → *mim* 。中文照样能判：「给我」→ *mim* ，「给我 **读** 」→ *eu* 。
- *entre* 后面同样如此： *entre **mim** e você* （你我之间），不是 *entre eu* 。
- 口语里 **com a gente** 远远压过 *conosco* ，而 *contigo* 只活在 *tu* 还活着的地方。
- *si* 和 *consigo* 是反身用法（相当于中文的 **自己** ），在巴西很少见。认得就够，不必主动用。

### 为什么重要？

葡语的每一个介词都需要这套形式，所以它在你学葡语的第一个小时就出现，此后再没停过： *para mim* （给我）、 *com ele* （和他）、 *sem você* （没有你）、 *depende de nós* （取决于我们）。

把 *mim* 和 *eu* 弄反，句子还能一瘸一拐地走完，但这是巴西人在书面语里最快察觉的一个特征—— *para mim fazer* 是「没读完书」的典型标记。现在花一秒学会那个判断法，就能一开始就避开一个多数母语者一辈子都改不掉的错误。

中文母语者在这里有一个 **特别好的支点** 。葡语在这里区分的东西，中文每天都在用 **有没有动词** 来区分：「他买了本书 **给我** 」和「他买了本书 **给我读** 」——没有中国人会把这两句搞混。同一个判断，原样搬到葡语上即可。

### 深入解析

### 1\. 全表——几乎什么都不变

在代词前面放一个介词，葡语会要求一个特殊形式——但只要求两次。

| 主格形式 | 介词后 | 例句 | 意思 |
| --- | --- | --- | --- |
| eu | **mim** | Isso é para **mim**. | 这是给我的。 |
| tu | **ti** | Comprei um doce para **ti**. | 我给你买了颗糖。 |
| você | **você** | Trouxe isso para **você**. | 我给你带了这个。 |
| ele / ela | **ele / ela** | Falei com **ela** ontem. | 我昨天跟她谈过。 |
| nós | **nós** | Guarde um lugar para **nós**. | 给我们留个位子。 |
| a gente | **a gente** | Isso é ótimo para **a gente**. | 这对我们来说太好了。 |
| vocês | **vocês** | Tenho uma notícia para **vocês**. | 我有个消息要告诉你们。 |
| eles / elas | **eles / elas** | Mandei o convite para **eles**. | 我把请柬寄给他们了。 |

两个变、六个不变。只有 *eu* → **mim** 和 *tu* → **ti** 换了模样，其余就是你已经认识的主格代词，安静地站在介词后面。每一个介词后面都一样： *de mim* 、 *sem mim* 、 *por mim* 、 *em mim* 、 *entre mim e você* 。

这里和中文的思路正好相反。中文是 **介词换、代词不换** ——给我、跟我、为我，「我」永远是「我」。葡语是 **介词不换、代词换** 。会变的只有两个，负担很小，但方向是反的，值得先记住。

### 2\. com 会把代词吞掉

*Com* 拒绝和其中三个形式并排站，它把它们融成一个词：

| com + | \= | 例句 | 意思 |
| --- | --- | --- | --- |
| eu | **comigo** | Vem **comigo**! | 跟我来！ |
| tu | **contigo** | Quero falar **contigo**. | 我想跟你聊聊。 |
| nós | **conosco** | Ela vai **conosco**. | 她跟我们一起去。 |

其余都不融合。 *Com você* 、 *com ele* 、 *com ela* 、 *com vocês* 、 *com eles* 、 *com a gente* 都保持两个词。

关于人们实际怎么说，有两条注意。会话里 **com a gente** 大幅压过 *conosco* —— *Fica com a gente hoje!*（今天留下来跟我们一起吧！）才是日常句， *conosco* 属于信件、告示和公司标语。可以理解成中文书面语和口语的距离。而 **contigo** 跟着 *tu* 走：南部、东北部一些地方、里约。全国其余地方就直接说 *com você* 。

还有一个值得知道的例外： *nós* 一旦带上修饰语，融合就散开，重新变回两个词—— *Ele foi com **nós dois**.*（他和我们两个一起去的。）

### 3\. 关键在这里：para mim 还是 para eu？

判断法就一句，一秒钟： **代词后面紧跟着动词吗？**

- 后面只有句子的其余部分 → 代词只是介词的宾语 → **mim** 。
- 后面跟着一个不定式 → 代词是那个动词的 **主语** → **eu** 。

用中文想，根本不会犹豫： **「给我」用 mim，「给我做／读／看」用 eu** 。

| 只是宾语 → *mim* | 下一个动词的主语 → *eu* |
| --- | --- |
| Isso é para **mim**.（这是给我的。） | Isso é para **eu** fazer.（这是要我来做的。） |
| Ela trouxe um café para **mim**.（她给我带了杯咖啡。） | Ela trouxe um café para **eu** beber.（她带了杯咖啡给我喝。） |
| Não é fácil para **mim**.（这对我不容易。） | Não é fácil para **eu** dirigir aqui.（我在这里开车不容易。） |
| Ele guardou um lugar para **mim**.（他给我留了个位子。） | Ele guardou um lugar para **eu** sentar.（他留了个位子给我坐。） |

看右边一列的中文：每一句里「我」后面都跟着一个动词。左边一列则没有。葡语用代词的形式标出来的区别，中文用 **有没有那个动词** 标出来——同一个区别，不同的工具。

同样的判断对其他代词也有效，只是它们不变形： *para **você** ver* （给你看）、 *para **ele** decidir* （让他来决定）、 *para **a gente** resolver* （让我们来解决）。

*Entre* 是同一条规则的另一面。代词后面只有另一个人，没有动词，所以用素的宾语形式： *Isso fica **entre mim e você**.*（这事就我们俩知道。）

现在说实话的部分。同一个「要我来做」用 *mim* 说成 ***para mim fazer*** ，到处都是。你会从各种背景的巴西人口中、在这个国家的每个角落听到它。它是这门语言里传播最广的非标准结构之一，同时也是最容易被注意到的之一。在作文、考试或求职材料里，它读作「没受过教育」。所以请学会 *para eu fazer* 并使用它，同时也不必对桌子对面的人说另一种感到惊讶。

### 4\. si 和 consigo：认得就够

这两个是反身用的，指回句子的主语。相当于中文的 **自己** 。

- *Ele só pensa em **si**.*（他只想着自己。）
- *Ela levou o cachorro **consigo**.*（她把狗带在身边。）

在日常巴西你几乎用不到它们。人们说 *Ele só pensa nele mesmo* 、 *Ela levou o cachorro com ela* 。把 *si* 和 *consigo* 放在认知层面即可。还有一个陷阱：在葡萄牙， *consigo* 是客气的「和您」，所以欧洲葡语的文本在巴西人眼里会显得别扭。

### 5\. 你会在这些介词后面遇到它们

带介词的葡语动词会把代词形式一起拖在后面。就像中文用「 **跟** ……说」「 **对** ……感兴趣」「 **靠** ……」把动词和介词一起记那样，请把动词和介词当成一个单位。

| 动词 + 介词 | 例句 | 意思 |
| --- | --- | --- |
| gostar **de** | Ela gosta muito de **mim**. | 她很喜欢我。 |
| precisar **de** | Eu preciso de **você**. | 我需要你。 |
| depender **de** | Isso depende de **nós**. | 这取决于我们。 |
| pensar **em** | Pensei em **ti** o dia todo. | 我一整天都在想你。 |
| falar **com** | Ele já falou **comigo**. | 他已经跟我谈过了。 |
| contar **com** | Pode contar **comigo**. | 你可以指望我。 |
| cuidar **de** | Quem cuida de **vocês**? | 谁照顾你们？ |

这里有一个强制的融合： *de* 和 *em* 会黏到 *ele, ela, eles, elas* 上。 *Gosto **dele*** 、 *Preciso **dela*** 、 *Pensei **neles*** 。 *De ele* 和 *em ela* 就像 *de o* 和 *em a* 一样不可能。第一、第二人称的形式保持松散： *de mim* 、 *de você* 、 *de nós* 、 *de vocês* 。

### 6\. 已经有 me 和 te 了，为什么还要这一套？

*Ele me deu o livro* 和 *Ele deu o livro para mim* 都是「他把书给了我」。长的那个存在，是为了 **分量** ：它把聚光灯打在「给谁」上： *Ele deu o livro **para mim**, não para você.*（他把书给的是 **我** ，不是你。）就像中文重读「给 **我** 」的效果。

还有一点：在不属于动词的介词后面，你只有这一个选择。 *sem mim* （没有我）和 *depois de mim* （在我之后）没有对应的短代词。

### 常见错误

- **说 *com eu* 或 *com nós* 。** 融合不是可选项：❌ *Você vai com eu?* → ✅ *Você vai **comigo**?*（你跟我一起去吗？）以及 ❌ *Ele mora com nós* → ✅ *Ele mora **com a gente**.*
- **用 *mim* 回答问题。** ❌ *— Quem quer café? — Mim!* → ✅ *— **Eu**!*（我！）单独的回答是主语，主语用 *eu* 。中文回答「我！」时那个「我」也是主语，思路一致。
- **过度修正成 *para eu* 。** *para eu fazer* 的规则一旦想通，人就想到处用：❌ *Este presente é para eu* → ✅ *Este presente é para **mim**.* **后面翻不出动词，就不是 *eu* 。**
- **为了显得正确而去用 *ti* 。** *Ti* 是真的，但属于 *tu* 的地盘；在其他地方用 *para ti* 会像歌词。✅ *Trouxe um café para **você**.*
- **写成 *de ele* 或 *em ela* 。** 必须融合：❌ *Eu gosto de ele* → ✅ *Eu gosto **dele**.* ❌ *Pensei em ela* → ✅ *Pensei **nela**.*
- **在随意的会话里用 *conosco* 。** 完全正确，但浆得有点硬：✅ *Vem **com a gente**!* 才是人们真正说的。 *Conosco* 留给要写下来的东西。
- **固定代词、去找介词。** 中文的习惯是「我」不动、换介词，照这个思路选就会冒出 *para eu* ／ *com eu* 。葡语相反： **介词固定，代词动。**
