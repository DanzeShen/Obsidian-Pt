# 核心介词：em、de、para、com、por

em、de、para、com、por 这五个介词是葡语里最高频的一组功能词，用来表达地点、来源、目的、陪同和原因，也是初学者最容易混淆的一组。

### 结构

介词 + 冠词 = 缩合 | em + o = no | de + a = da | para + o = pro（口语）


### 快速概览

- **Em** = 在……里 / 上 / 处于（地点、时间）：em casa, no Brasil
- **De** = 来自 / ……的 / 关于：de São Paulo, casa de João
- **Para** = 去 / 为了 / 给：para casa, para você
- **Com** = 和……一起 / 带着：com amigos, com leite
- **Por** = 通过 / 因为 / 由：por favor, pelo parque
- **de / em / por** 和定冠词缩合是强制的
- **para** 在口语里常变成 **pra / pro**
- 同一个动词换一个介词，意思往往就变了
- 不要逐词直译介词

### 为什么重要？

介词就是葡语里的导航系统。没有它们，别人根本不知道你要去哪里、来自哪里、为了什么，也不知道动作是和谁一起完成的。你连 “café com leite”（咖啡加牛奶）或 “sou de São Paulo”（我来自圣保罗）这种最基础的话都离不开这些小词。

如果介词用错，本来想说 “para casa”（回家），可能就会说成别的意思，整句话立刻跑偏。掌握这五个介词之后，很多句子结构会突然变得清楚。

### 深入解析

### 核心规则

- **em** 主要表示地点和时间。
- **de** 主要表示来源、所属、材料和内容。
- **para** 主要表示方向、接收对象和目的。
- **com** 主要表示陪同、状态和搭配。
- **por** 主要表示原因、路径、交换和施事。

### 缩合提醒

- **em** 和冠词缩合：no / na / nos / nas
- **de** 和冠词缩合：do / da / dos / das
- **por** 和冠词缩合：pelo / pela / pelos / pelas
- **para** 在口语里常变成 pra / pro

### 高频固定搭配

- gostar **de**
- precisar **de**
- ir **para**
- ir **de**
- ir **com**

### 学习重点

不要把葡语介词逐词硬译成中文或英文。很多时候，真正要记的是"动词 + 介词"这个整体。

### 例子

### 日常地点（EM）

- "Estou **no** trabalho."（我在上班 / 我在工作地点。）
- "Moro **em** Copacabana."（我住在科帕卡巴纳。）
- " **Na** segunda-feira."（在星期一。）
- " **No** verão."（在夏天。）

### 来源和所属（DE）

- "Venho **do** Rio."（我来自里约。）
- "A casa **da** minha mãe."（我妈妈的房子。）
- "Gosto **de** pizza."（我喜欢披萨。）
- "Perto **da** praia."（靠近海边。）

### 目的地和用途（PARA）

- "Vou **para** o supermercado."（我要去超市。）
- "Isso é **pra** você."（这是给你的。）
- "Estudo **para** passar."（我为了通过考试而学习。）
- " **Pro** ano que vem."（留到明年 / 为了明年。）

### 陪同和状态（COM）

- "Saio **com** amigos."（我和朋友出去。）
- "Café **com** açúcar."（加糖咖啡。）
- "Estou **com** pressa."（我赶时间。）
- "Moro **com** meus pais."（我和父母一起住。）

### 原因和路径（POR）

- "Obrigado **por** tudo."（谢谢你所做的一切。）
- "Pago **por** Pix."（我用 Pix 支付。）
- " **Pelo** amor de Deus!"（看在上帝的份上！）
- "Ando **pela** cidade."（我在城里到处走。）

### WhatsApp 风格

- "to **na** praia" （我在海边）
- "vem **pra** cá" （过来这边）
- "saindo **do** trabalho" （刚下班）
- " **com** vc" （和你）

### 常见例外

### para / pra 的口语现实

日常口语里，很多人几乎不完整说 **para** ：

- 书面：para o
- 口语：pro
- 更随口：pra / pa

### 交通工具里的 em 和 de

- Vou **de** carro.（我开车去 / 乘车去，强调方式）
- Vou **no** carro.（我坐那辆车去，强调具体那辆车）

两种都可能正确，只是角度不同。

### com + 饥饿 / 口渴 / 困

葡语常用 **com** 表示身体状态：

- com fome（饿）
- com sede（渴）
- com sono（困）

### gostar 的固定陷阱

**Gostar** 后面基本一定要接 **de** ：

- Gosto **de** música.
- 不能直接说 “Gosto música”.

### 方向和位置不能混

- Vou **para** casa.（往家去，移动）
- Estou **em** casa.（在家里，位置）

### por 和 para 都可能表示“为了”，但逻辑不同

- Estudo **para** passar.（为了通过，目标）
- Estudo **por** prazer.（因为喜欢而学，原因）

### 有些形式已经直接融合成单词

- de + ele = **dele**
- de + este = **deste**
	这类形式通常不能再拆开写。

### 趣闻

### "Pelo" 和 "pela" 里藏着一个更老的葡语介词

**pelo、pela、pelos、pelas** 这几个缩合形式保留了中世纪的介词 **per** （"经由、通过"），后来 *por* 取代了它的独立用法。所以你说 *pela rua* （沿着这条街）的时候，其实是在用古早的 *per la* 化石——这个介词作为独立的词已经从语言里消失了，但是在缩合形式里还活着。

*来源： [Wiktionary — pelo (词源)](https://en.wiktionary.org/wiki/pelo) 、 [Wiktionary — por (词源)](https://en.wiktionary.org/wiki/por) 。*

### "Por" 和 "para" 来自同一个拉丁词

两个介词都来自拉丁语 **prō** （"为了、代表"）。 *por* 是在拉丁语 **per** 影响下经过音变形成的，而 *para* 来自拉丁语 **prō + ad** （"为了 + 朝向"）的合并，先经过中世纪葡语的 **pora** ，最后才稳定成现代的 *para* 。在今天的葡语里，它们各管一摊： *para* 主管方向和目的， *por* 主管原因、路径和交换——其实是同一个拉丁词分出来的两条线。

*来源： [Wiktionary — por (词源)](https://en.wiktionary.org/wiki/por) 。*
