# 口语缩略：tá、cê、pra、né、vambora

巴西人按可预测的方式压缩发音：词丢掉头一个音节（está 变 tá，você 变 cê）、相邻的词熔在一起（vamos embora 变 vambora）、词尾磨损（falando 听起来像 falano）。中文也有同一类现象—— **不用→甭、这样→酱、什么→啥、怎么→咋** ——所以「压缩」本身对你不陌生。本节讲清楚缩略背后的机制，让快速的口语重新变得可辨认，并划出一条清楚的线：哪些可以说，哪些必须照原样写。

### 结构

书面完整形式 → 你实际听到的：você está falando → cê tá falano

### 快速概览

- **三个动作解释了几乎全部：** 口语会 **削掉词头** 、把邻居 **熔在一起** 、让 **词尾磨损** 。中文的「甭、酱、啥」属于第二种，轻声属于第三种。
- **削掉词头：** *está* → **tá** 、 *estou* → **tô** 、 *estamos* → **tamo** 、 *estão* → **tão** 、 *você* → **cê** 、 *vocês* → **cês** 。 **这一招中文几乎没有** ，因为汉语每个音节都带声调，不会被压掉。
- **熔在一起：** *vamos embora* → **vambora** → **bora** ； *espera aí* → **peraí** ； *não é* → **né** ； *o que é que* → **quê que** 。这一类正是中文的「甭、酱、啥、咋」。
- ***né* 就是中文的** 对吧／是吧 **。** 位置和功能都一样：放在句末，要的是点头而不是信息。
- **词尾磨损：** *falando* 听起来是 **falano** ，不定式的词尾 *\-r* 会消失—— *falar* → **falá** 。
- **叠在一起：** *Você está esperando o quê?* 变成 *Cê tá esperano o quê?*
- **语体：** 全部要 **听得懂** ，常用的（ *pra* 、 *tá* 、 *né* ）可以 **说** ，正式场合要 **写** 完整形式—— *para* 、 *está* 、 *você* 、 *não é* 。这条线你在中文里本来就会划。

### 为什么重要？

这是「做完一道语法题」和「跟上一段对话」之间的沟。一个把 *você* 、 *está* 、 *esperando* 都学得很扎实的学习者，照样会整句漏掉 *Cê tá esperano* ——因为教给他的音，和到达耳朵的音不是同一个。

没有任何新东西被说出来，词只是穿上了家常衣服。把缩略当成 **一套机制** 而不是一百个俚语来学，意味着第一次遇到不熟悉的压缩也解得开。这也是让你说话不再像教科书的最快办法。

中文母语者可以直接信任这套机制。能把「甭」还原成「不用」、把「酱」还原成「这样」的人，把 *tá* 还原成 *está* 不会有任何障碍。 **你需要的不是新能力，只是一张对照表。**

### 深入解析

### 1\. 不是一百个俚语，是三个动作

巴西口语不是随机地缩。你会遇到的压缩几乎每一个都属于下面三类，而且常常在一个短句里同时发生。

| 动作 | 发生了什么 | 葡语例子 | 中文里的同类 |
| --- | --- | --- | --- |
| **削掉词头** | 不带重音的第一个音节掉了 | *está* → **tá** | 几乎没有（汉语音节带调，压不掉） |
| **熔在一起** | 相邻的词化成一个 | *não é* → **né** | 不用→ **甭** 、这样→ **酱** |
| **词尾磨损** | 最后的音变弱或消失 | *falando* → **falano** | 轻声：东 **西** dōngxi |

下面的写法都是巴西人把口语落到纸上时——歌词、漫画、WhatsApp——实际会写的形式。每个缩略形式旁边都标出它来自的完整形式，因为要写的是完整形式。

### 2\. 削掉词头：estar 和 você

随意会话里最高频的两个词，也是缩得最厉害的两个。 **这一招在中文里没有对应** ，因为汉语的每个音节都带声调，不会被压成零。所以这一节请当成纯粹的新内容来记。

## estar —— 主力

| 完整形式 | 你听到的 | 意思 |
| --- | --- | --- |
| estou | **tô** | 我是／在 |
| está | **tá** | 你／他／她是／在 |
| estamos | **tamo** （也写 *tamos* ） | 我们是／在 |
| estão | **tão** | 他们是／在 |

- *Tô com fome.*（我饿了。）← *Estou com fome.*
- *Ela tá dormindo.*（她在睡觉。）← *Ela está dormindo.*
- *Tamo esperando.*（我们在等。）← *Estamos esperando.*

*Tá* 还挣脱了动词，自己成了一个词，意思是 **「行」** ：

- *Te ligo mais tarde, **tá**?*（我晚点打给你，行吗？）
- *— Chega às oito. — **Tá**.*（—八点到。—行。）

那是 *está bom* （那样可以）一路磨到底的结果： *está bom* → *tá bom* → *tá* 。和中文「没问题」→「没事儿」→「成」的路径一样。

## você —— 缩到一个音节

| 完整形式 | 你听到的 | 意思 |
| --- | --- | --- |
| você | **cê** | 你 |
| vocês | **cês** | 你们 |

- *Cê viu isso?*（你看到了吗？）
- *Cês vão na festa?*（你们去派对吗？）—— 动词保持复数： *vão* 。

有一条限制值得知道： **cê 太小，扛不住重音。** 它不能独自站立，也不能被强调，所以它从不单独回答问题，也不出现在你要强调的地方：

- ❌ *— Quem quebrou? — Cê!* → ✅ *— Quem quebrou? — **Você**!*（—谁弄坏的？—你！）
- ❌ *Eu não fiz nada. Cê fez!* → ✅ *Eu não fiz nada. **Você** fez!*（我什么都没做，是 **你** ！）

中文的缩略形式也有同样的限制：你可以说「甭管了」，但没法把「甭」单独喊出来当强调。感觉是一样的。

### 3\. 熔在一起：先是介词，然后是整个短语

介词那一半你在 **colloquial-contractions** 里已经见过： *para* → **pra** 、 *para o* → **pro** 、 *para a* → **pra** 。同一个机制，不再重复：

- *Vou pra praia.*（我去海边。）← *Vou para a praia.*

这里新的是，这层胶水也作用在 **整个短语** 上，而那些正是让句子变得认不出来的部分：

| 完整形式 | 你听到的 | 意思 |
| --- | --- | --- |
| vamos embora | **vamo embora** → **vambora** → **bora** | 走吧／我们撤 |
| espera aí | **peraí** | 等一下 |
| não é | **né** | ……对吧 |
| o que é que | **quê que** | 什么 |
| está bom | **tá bom** → **tá** | 行 |
| para com isso | **parcom isso** | 别闹了 |
| deixa eu ver | **xó vê** （也写 *xove* ） | 让我看看 |
| você está | **cêtá** | 你是／在 |

**这一整类正是中文的「甭、酱、啥、咋」。** 「不用」两个音节熔成「甭」一个， *vamos embora* 四个音节熔成 *bora* 两个——同一件事。

几条注记：

- **bora** 已经完全独立，本身就是一句邀请： *Bora almoçar?*（去吃午饭？） *Bora!*（走！）
- **quê que** 是 *o que é que…* 磨出来的： *Quê que você quer?*（你要什么？）
- **para com isso** 里的 *para* 根本不是介词，而是动词 *parar* （停）的命令式： *Para com isso!*（别闹了！）
- **xó vê** 没有定形的写法，因为它只活在嘴里。你会看到 *xó vê* 、 *xove* 、 *xo vê* ——都是 *deixa eu ver* （让我看看）。中文的「让我康康」也一样没有正字法。
- **cadê** （……在哪儿？）也属于这一族，你在 **basic-questions** 里见过： *Cadê o Pedro?*（佩德罗人呢？）

### 4\. 词尾磨损

第三个动作最安静，对学习者代价最大，因为它恰好落在语法课练得最狠的那些词尾上。

**动名词丢掉 *d* 。** *\-ndo* 的词尾以 *\-no* 到达：

| 完整形式 | 你听到的 | 意思 |
| --- | --- | --- |
| falando | **falano** | 正在说 |
| comendo | **comeno** | 正在吃 |
| dormindo | **dormino** | 正在睡 |
| fazendo | **fazeno** | 正在做 |

这就是为什么你整天都在用的 *estar + gerúndio* ，会以一个你认不出的形式落地： *Ele tá fazeno o quê?*（他在干吗？）

**不定式丢掉词尾的 *\-r* 。** 放松的口语里 *falar* 说成 *falá* ， *comer* 说成 *comê* ：

- *Vou falá com ele.*（我去跟他说。）← *Vou falar com ele.*
- *Bora comê?*（去吃饭？）← *Vamos comer?*

**词尾元音变色。** 不带重音的词尾 *\-e* 读成接近 \[i\]， *\-o* 读成接近 \[u\]。巴西各地、任何语体都这样，晚间新闻也不例外： *leite* （牛奶）听起来像「雷契」， *tudo* （全部）像「图杜」。

**这一段中文母语者反而占便宜。** *leite* 里的「契」和 *dia* 里的「基」，正是普通话里 **q/j** 那一类的音，你天天在发。英语母语者要专门学这个颚化，你不用。而且这不是语速也不是俚语，就是巴西葡语的标准发音，拼写永远不变。

### 5\. 同一个句子，说两遍

三个动作叠起来，沟就是这样的。下面每一行口语 **就是** 旁边那行书面语，什么都没加，只少了音节。

| 书面 | 口语 | 意思 |
| --- | --- | --- |
| *Você está esperando o quê?* | *Cê tá esperano o quê?* | 你在等什么？ |
| *O que é que vocês estão fazendo?* | *Quê que cês tão fazeno?* | 你们在干吗？ |
| *Espera aí, deixa eu ver.* | *Peraí, xó vê.* | 等一下，让我看看。 |
| *Vamos embora para a casa dela, não é?* | *Vambora pra casa dela, né?* | 我们去她家吧，对吧？ |

把右边一列大声念几遍。目标不是模仿它，而是当它以全速到达时，你能把它倒着放回去。

### 6\. 什么可以说，什么必须照原样写

这些缩略的社会分量并不相同，所以这里划一条实话的线。中文的书面语／口语界线怎么划，这里就怎么划。

- **每一个都要听得懂。** 这就是本节的全部目的。它们是正常的、受过教育的成年巴西人的说法，不是马虎，也不是青少年黑话。
- **常用的可以放心说。** *Pra* 、 *tá* 、 *tô* 、 *né* 、 *cadê* 、 *peraí* 、 *bora* 在随意对话里对谁都安全，包括在公司。
- **属于口语的地方可以打出来。** *Pra* 、 *tá* 、 *né* 、 *cadê* 在给朋友的消息里完全正常。
- **其他地方一律写完整形式。** 作文、求职材料、给不认识的人写邮件： *para* 、 *está* 、 *você* 、 *não é* ，没有例外。
- **有些只属于说的。** *cê* 、 *falano* 、 *xó vê* 、 *cêtá* ，除了要把声音落到纸上（对白、歌词、漫画），没人会写。在普通消息里它们读起来像玩笑或录音转写。

### 常见错误

- **听到什么就写什么。** ❌ 工作邮件里写 *Vou mandar o relatório pra você amanhã* → ✅ *Vou mandar o relatório **para** você amanhã.*（我明天把报告发给您。） *Pra* 在给朋友的消息里没问题，在任何正式场合都不行。中文里你也不会把「甭」写进报告。
- **让 *cê* 承担强调。** *Cê* 本来就不带重音，做不了句子里最响的那个词。❌ *Foi cê!* → ✅ *Foi **você**!*（就是你！）
- **以为 *tá* 一定是动词。** 单独站着时， *tá* 通常根本不是「是／在」，而是「行」。 *— Me espera lá embaixo. — **Tá**.*（—在楼下等我。—行。）
- **把 *tão* 只听成「这么」。** *Tão* 既是 *estão* （他们是／在），也是表示程度的「这么」，只有上下文能分开： *Eles tão cansados.*（他们累了。）对照 *Eles estão tão cansados.*（他们累成那样。）
- **以为 *bora* 是 *ir* 的一个形式。** 它来自 *vamos embora* ，「我们走」已经装在里面了。你还是会听到叠用的 *Vamo bora!*（走吧！）——纸上冗余，嘴上完全正常。
- **把 *né* 当成真的疑问。** *Né* 要的是同意，不是信息。 **它就是中文的「对吧」。** *Tá quente hoje, né?*（今天挺热的，对吧？）是在钓一个点头，不是在等答案。
- **什么都想缩。** 压缩落在不带重音的高频词上。带重音的词保持原样—— *você* 会缩成 *cê* ，但 *eu* 、 *mim* 、 *ele* 已经没什么可掉的了。
